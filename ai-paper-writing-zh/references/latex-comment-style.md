# LaTeX 中文注释风格

使用原生 LaTeX 注释，让用户可以直接在论文源文件中修改。

## 基本模式

```tex
% [段落目标] 说明该段在论文叙事中的作用。
% [核心内容] 用一到三句话概括要写什么。
% [证据] 指向已有实验、图表、定理或分析；未知内容写 TODO。
% [衔接] 说明该段如何连接上一段和下一段。
```

更短的计划可以写成：

```tex
% 本段：引出 xxx 问题；强调现有方法在 xxx 上不足；最后过渡到我们的观察。
```

## 章节标题模式

```tex
\section{Introduction}
% 本节目标：建立问题重要性，明确 prior work gap，引出核心观察和方法贡献。
% 摘要锚点：本文主张 [TODO: 用一句话确认论文主线]。
```

## 段落注释规则

- 骨架阶段优先写简洁中文注释，而不是润色后的中文正文。
- 一个段落只承担一个叙事任务。
- 在需要缺失事实的位置写 TODO。
- 保持 label、citation、math、macro 和模板命令不变。
- 除非用户要求，否则不要注释掉重要模板命令。

## 扩写模式

扩写注释时仍保持可编辑：

```tex
% [中文扩写]
% 这里首先说明 xxx 背景。随后指出当前方法通常依赖 xxx，因此在 xxx 场景下会遇到 xxx 问题。
% 我们的核心观察是 xxx；这一观察直接导向后文的 xxx 设计。
% [TODO: 加入最能支持该观察的实验或引用]
```

## 翻译前准备

翻译一个注释段落前，确认它具备：

- 段落功能
- 已确认主张
- 支撑证据或 TODO
- 与论文主线的连接
